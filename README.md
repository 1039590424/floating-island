# Personal Workstation / 个人工作站

A dual-purpose personal website deployed on GitHub Pages:
- **Showcase** (default): personal profile, skills, projects, insight cards
- **Tools** (sidebar): dashboard, quick tools, knowledge base, tasks

一个部署在 GitHub Pages 上的双用途个人网站：
- **展示层**（默认可见）：个人简介、技能、项目、感悟卡片
- **工具层**（侧边栏拉出）：工作台、快捷工具、知识库、任务日程

## Quick Start / 快速开始

Open `index.html` in a browser. No build step required.

直接用浏览器打开 `index.html` 即可，无需构建。

## Tech Stack / 技术栈

- HTML + CSS + JavaScript (ES Modules)
- No framework, no build tools
- Data in JSON, stored locally in browser

## Design Style / 设计风格

Nintendo-inspired: bright, friendly, warm. Practical first, playful second.

任天堂游戏风格：明快、友好、有温度。实用优先，有趣味性。
